😊 Face Emotion Detection

📌 Overview

This project detects human emotions from facial expressions using Machine Learning and Computer Vision.

🚀 Features

- Real-time face detection
- Emotion classification (Happy, Sad, Angry, Surprise, etc.)
- Works with webcam input / image input

🛠️ Technologies Used

- Python
- OpenCV
- TensorFlow / Keras (or mention what you used)

▶️ How to Run

1. Install required libraries:
   pip install opencv-python tensorflow numpy
2. Run the program:
   python main.py

📊 Output

The system detects a face and displays the predicted emotion on screen.

📁 Project Structure

- main.py
- model.h5
- dataset/
- utils/
